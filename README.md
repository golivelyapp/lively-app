# Lively

Flutter dating app. Riverpod + GoRouter + Supabase.

```
lib/
  core/      shared: api client, theme, router, utils
  features/  auth, onboarding, profile, discovery, matching, chat, settings
```

## One-time machine setup (not yet done on this machine)

Flutter/Dart SDK is not installed here. Install it yourself, then verify:

```bash
brew install --cask flutter
flutter doctor
```

`flutter doctor` will flag anything still missing (Xcode, CocoaPods, Android
Studio/emulator image) — follow its instructions for each platform you want
to run on.

## Generate platform folders

This repo currently has only `lib/` and `pubspec.yaml` — no `ios/`/`android/`
folders yet, since those must be generated by the installed SDK:

```bash
cd "/Users/yash/Documents/Lively App"
flutter create --project-name lively --org com.lively .
flutter pub get
```

## Configure Supabase

```bash
cp .env.json.example .env.json
# fill in SUPABASE_URL and SUPABASE_ANON_KEY from your Supabase project
```

## Run

```bash
flutter run --dart-define-from-file=.env.json
```

## Code generation (freezed / riverpod_generator)

Run after adding/changing any `@freezed` model or `@riverpod` provider:

```bash
dart run build_runner build --delete-conflicting-outputs
```
